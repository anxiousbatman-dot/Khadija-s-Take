Put your pictures in this folder with these names (or change the names in posts.js / style.css):

banner.jpg    - the header image, about 900 x 170 px. Shown behind the site name.
welcome.jpg   - small picture beside the greeting box, about 110 x 130 px.
Post images   - any name you like. Add  image: "images/yourfile.jpg"  to a post in posts.js
                for a small thumbnail (about 130 x 130 px) next to its summary.

Missing pictures are simply hidden, so the site works while you add them.
